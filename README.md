# process-sentinel

A cross-platform desktop app that monitors and automatically restarts critical processes with configurable retry logic and real-time logging.

## Stack

Primary language: **TypeScript**

## Project structure

- `src/App.tsx` — Main React application component managing the UI state, process list, and log viewer.
- `src-tauri/src/main.rs` — Rust backend handling process spawning, monitoring, and Tauri commands

## Usage

Review the source files and install any dependencies referenced by the project before running it.
